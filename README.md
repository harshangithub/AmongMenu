# Among Us Overlay Project

This project is focused on creating an overlay for the popular game *Among Us*. The overlay displays important information related to the game, including:

- **Imposters:** Shows the players assigned as imposters.
- **Distance:** Calculates and displays the distance between players.
- **Room:** Indicates the current room the player is in.
- **Tracers with Distance-based Coloring:** Visualizes player movement with tracers that change color based on the distance to other players, providing a clear and informative experience.

This tool aims to enhance gameplay by providing vital information at a glance and improving strategic planning during matches.
